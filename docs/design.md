# IMG_FILTER 设计说明（简版）

完整的设计叙述、五轮开源物理实现和时序收敛研究见上一个仓库
[vfir-7nm-rtl2gds](https://github.com/stevenchen0830/vfir-7nm-rtl2gds)。
本文只保留理解 `rtl/img_filter.v` 所需的最小内容，章节编号与 RTL 中的
`// N.` 分节一致。

## 1. 数据流

```
in_pix_data ──REG_IN──▶ 2 槽输入 FIFO ──▶ 写入 bank (r mod 49) ┐
                                        └─ 旁路第 50 抽头 ────────┤
                                                                  ▼
mem_rdata ──REG_IN──▶ rdata_q (49×160b) ──▶ 16 lane × 50 抽头 MAC (3 级)
                                                                  │
                                       out_pix_data ◀──REG_OUT── 2 槽输出 skid
```

- 每拍 4 像素 × 4 分量 = 16 条 10-bit lane，全部并行。
- 行 `m` 存放在 bank `m mod 49`，地址 = 行内拍序号 `c`；所有 bank 共用一个地址，
  数据写入后不再搬移。
- 正在输入的行不经过 SRAM，而是从输入寄存器旁路成为第 50 个抽头，
  空出的 bank 恰好接收本拍写入：**同一拍 48 读 + 1 写 = 49 片单端口 SRAM 用满**。

## 2. 系数旋转而非数据旋转（第 4 节）

对输出行 `y`，每行只算一次 392-bit 的“等效权重向量”

    C[j] = Σ { coef_k | mirrorMap(y+k, H) mod 49 == j }

由对称系数数组的三次旋转（内部抽头 / 上边界折叠 / 下边界折叠）相加得到。
两个折叠到同一源行的抽头权重直接相加，镜像逻辑因此完全离开数据通路；
数据通路只剩一个无镜像的 50 项 MAC。

- 旋转量 `s1 = (y+25) mod 49`、`s2 = (23-y) mod 49`、`s3 = ((2H+23) mod 49 - y) mod 49`，
  其中 `(2H+23) mod 49` 在 PREP 阶段用 8 次条件减法算出（`mod_x`）。
- 旋转器拆成 `rot49_lo`（+1/+2/+4）和 `rot49_hi`（+8/+16/+32）两级流水，
  两级之间 1,193 bit 寄存器；权重向量提前一行准备好（`c_fut` → `c_cur`），
  行边界只是一次寄存器到寄存器的搬移。
- 读使能 `ce = (C[j] != 0)`：权重为 0 的 bank 不读，外部访存随 `blk_v`
  线性缩放，`blk_v = 1` 时零访存。

## 3. 帧序列（第 3 节）

`IDLE → PREP(13 拍) → FILL → MAIN → DRAIN → IDLE`

| 状态 | 输入 | 输出 | 说明 |
| --- | --- | --- | --- |
| PREP | 关 | 关 | 装载 `a_sym`、算 `mod_x`、生成首行权重向量 |
| FILL | 开 | 关 | 前 `(blk_v-1)/2` 行只写 SRAM |
| MAIN | 开 | 开 | 稳态：每拍 1 写 + ≤48 读 + 1 输出 |
| DRAIN | 关 | 开 | 最后 `(blk_v-1)/2` 行只读 |

帧延时（首拍输入到首拍输出）= `(blk_v-1)/2` 行时间 + 常数拍，
与 `blk_v` 成正比，满足题目对 latency 的要求；吞吐恒为 4 像素/拍。

## 4. 弹性接口（第 5、8 节）

两个流接口都终止在 2 槽寄存器 FIFO 上，`pipe_en` 只由寄存器决定
（FIFO 计数 + 状态），握手信号不直接驱动 7,840 位 `rdata_q` 的使能——
这是第一次物理实现时唯一无法修复的时序墙，改成寄存器 FIFO 后消失。

## 5. MAC（第 7 节）

mac4 分支：50 个 10×8 乘积先寄存 → 25 个对加 → 5 个部分和 → 总和 + 64 >> 7 + 饱和，
四级流水（`main` 为三级：乘加合并在第一级）。最深级是裸乘法器，
级数见 `scripts/logs/depth_ltp.txt`。所有中间值非负且
系数和为 128，20-bit 累加器无溢出。

## 6. 复位与时钟门控

- `rst_n` 异步置位、外部同步撤离；数据通路寄存器（`rdata_q`、`pair_q` 等
  约 2.1 万位）故意不复位，靠 `ce_d2` / `cbp_d2` 掩零阻断 X 传播。
- 所有大位宽使能寄存器都写成 `if (en) q <= d` 形式，DCG 的
  `compile_ultra -gate_clock` 会推断为 ICG；ICG 的额外 0.10 ns setup
  uncertainty 在 `syn/dcg/constraints.tcl` 中以 `set_clock_gating_check` 施加。
